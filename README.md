# My Task List

## Name
Armaan Nasri

## Application Name
My Task List

## Description
My Task List is a simple interactive web application that allows users to create and manage tasks.

Users can add tasks, select a priority level, mark tasks as completed, and delete tasks.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Enter a task and select a priority.
5. Click Add Task.

## Known Problems

Tasks are not saved after the page is refreshed.
